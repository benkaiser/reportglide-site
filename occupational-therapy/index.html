Review the draft

Fictional writing example

Clearer wording. The same finding.

Supplied note

Parent says needs verbal prompts for shower routine. Not observed this visit. Dressing independent per parent.

Report wording

The parent reports that verbal prompts are needed for the shower routine. This was not observed during the visit. The parent reports independent dressing.

Illustrative wording, not a clinical recommendation or a validated product output. It does not turn a parent report into a practitioner observation.

What it won’t do
